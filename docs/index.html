Install

  1. Plug the GateMaster board into this computer with a USB cable. The gate does not need to be connected.
  2. Click Install on a GateMaster board and choose the USB port (it may be called USB-SERIAL CH340, CP2102 or similar).
  3. When it asks, choose your home Wi-Fi and enter its password.
  4. Click Visit device. The gate's page opens – no address to type. Set a password on the first visit.

This browser cannot install firmware. Use Chrome or Edge on a Windows, Mac or Linux computer. Open this page over https (the github.io address) to install.

Takes about two minutes. Works in Chrome and Edge on desktop computers.

Already installed?

Plug the board in and click the same button, then choose the port:

  • Visit device opens the gate's page – handy when you don't know its address.
  • Change Wi-Fi moves it to another network.
  • Install updates it (settings are kept unless you choose to erase).

On your home network the gate is also always at http://gatemaster-xxxx.local – the four characters are shown on the gate's page and on this installer. Updates can also be installed from the gate's own page (General → Firmware), with no cable.

Testing on a plain ESP32 DevKit

Any ESP32 board with 4 MB flash works. This version starts with a simulated gate: the page gets a Simulator tab for photo-eye, safety edge, EXIT, radio, buttons, obstacles and faults, and nothing is driven except the board's blue LED (it blinks with the gate's heartbeat). For a factory reset, hold the DevKit's BOOT button for 10 s within a minute of plugging it in.

Use Chrome or Edge on a desktop computer. Open this page over https.

The mode can be changed later on the gate's page (General → Advanced → Hardware). Never use Simulator on a board installed at a gate.

If the USB port does not show up

  • Try another cable – some are charge-only.
  • Windows 10/11 and macOS include the CH340 driver. Older Windows: install the WCH CH340 driver. DevKits with a CP2102 chip need the Silicon Labs driver.
  • If the board's Wi-Fi details are wrong, it opens a setup network called GateMaster-xxxx about a minute after starting. Join it with a phone; the setup page opens by itself.
